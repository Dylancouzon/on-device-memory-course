# Object photos

Six subjects, two or three photos of each: backpack, gaillardia, hardhat, lithops, rubberduck, vase. Each set is several views of the same physical object, which is what L6 needs to teach recognition from a handful of examples and then test on a view it never saw.

L6 uses the rubber duck by default. The other five are here so you can teach a different subject without leaving the notebook: put the filenames in `TEACH_PHOTOS` and `TEST_PHOTO` in the first cell, for example `["./ro_shared_data/objects/vase_1.jpg", "./ro_shared_data/objects/vase_2.jpg"]` to teach and `"./ro_shared_data/objects/vase_3.jpg"` to test.

Photo credits, with author and license for each file, are in `CREDITS.json`.
