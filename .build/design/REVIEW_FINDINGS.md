## Verdict

The hands-on arc lands: L2 through L5 read as a single field being taught — store/recall/forget/persist, then selective recall, then a whole day, then recognition folding into "I built the whole thing" — with the Qdrant Edge API kept visible exactly where the rules require and everything else pushed into helpers. Every payoff I could check against saved notebook output matched the registry precisely, including the two hardest guards (forgotten-note-stays-forgotten after restart, and the ramen memo surviving in the capstone). Where it doesn't yet land is at the seams the restructure didn't finish sweeping: the marketing/Lesson-0 script is a full generation out of date and would misdescribe the course if shipped, one data README still names the old lesson number for Whisper, and a couple of shared helpers (`add_filler`, `before_after`'s hardcoded legend, `receipt_table`'s default title) leak either a hidden Qdrant call or an off-voice/misleading word into an otherwise disciplined set of notebooks. None of these need a rebuild — they're localized fixes — but the marketing script in particular should not go in front of camera as written.
